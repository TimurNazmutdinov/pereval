# Перевал

Маршруты, погода и навигация в горах.

- Построение маршрута по тропам на карте
- Погода в каждой точке пути в момент, когда вы туда дойдёте
- 3D-рельеф и пролёт над маршрутом
- Офлайн-карты и сохранённые маршруты
- Навигация по GPS с предупреждением об уходе с маршрута
- Лучший день для похода, многодневные походы, карточка безопасности, сравнение плана и факта

## Как выложить приложение (GitHub Pages, бесплатно)

1. Зарегистрируйтесь на github.com.
2. Нажмите «+» вверху справа → **New repository**. Название: `pereval`. Оставьте **Public**. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Перетащите в окно **всё содержимое** этой папки: `index.html`, `manifest.webmanifest`, `sw.js`, `README.md` и папку `icons`. Нажмите **Commit changes**.
5. Откройте **Settings** → **Pages**. В разделе **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
6. Через 1–2 минуты вверху страницы Pages появится адрес вида `https://ВАШЕ-ИМЯ.github.io/pereval/`.

## Как установить на телефон

- **Android (Chrome):** откройте адрес, нажмите кнопку «Установить приложение» в шапке или меню ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте адрес, нажмите «Поделиться» → «На экран „Домой“».

## Как обновить

1. Загрузите в репозиторий новый `index.html` (и другие изменённые файлы) с заменой.
2. В `sw.js` увеличьте версию: `pereval-v1` → `pereval-v2`.
3. При следующем запуске приложение предложит обновиться.
